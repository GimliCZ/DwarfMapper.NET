## The two defects the battery found

Neither was caused by new code. In both cases the gate already existed and simply had not been run since the
change that broke it — the same shape as every other finding this round.

**1. The conformance gate recorded a pass count no run ever produced** (fixed, `886fbb9`). ERE has no lazy
quantifier, so `.*?([0-9]+) passed` was a greedy match that ate the leading digits: every artifact ever
committed recorded `Passed: 8` for a 78-assertion run, 47 as 7, 72 as 2, 75 as 5 — each file contradicting
its own body. The gate *logic* was never affected (the total anchors on `(of `, so the ratchet always
compared the right number); only the evidence field was wrong. Also fixed: the RID defaulted to `linux-x64`
and filed this Windows run under that name.

**2. Sixteen of the hand-planted battery's 33 entries measure nothing** (recorded, not repaired, `da5de24`).
7 do not compile when applied, so the compiler catches them and the run prints `killed by <guard>` for a
guard that never ran; all 7 were already broken at the round-27 base. 9 are stale anchors, 6 of them broken
by this round's seam extraction. Full evidence and worklist:
[`FINDING-mutation-battery-catalogue-rot.md`](FINDING-mutation-battery-catalogue-rot.md).

The honest reading of that lane is **17 of 17**, not 24 of 33. Repairing the catalogue will *raise* the
denominator, and the score should be expected to fall before it rises.

The mutation battery refuses to run against a dirty tree, because it edits source in place and restores with
`git checkout`. Its guard tests the whole tree while its restore only touches `src/` and `docs/`, so
`.mcp.json` tripped a guard that could never have harmed it. Rather than weaken a safety guard to make a run
pass — or stash, with another session sharing the repository — the lane was run in a throwaway worktree, the
same pattern `scripts/repro-pack.ps1` already uses. The worktree was removed afterwards.

A green baseline was established inside that worktree first (7,111 passing, 0 failures). Without it, a suite
red for any unrelated reason would have marked every mutant "killed" and produced a perfectly vacuous 33/33.
