# Maintainers' records

This folder is the project's working history, not documentation for users of the library: per-round task ledgers
(`roundNN/`), audit and implementation ledgers (`ledgers/`), findings, research notes (`research/`), process
measurements and superseded plans (`history/`). Line numbers, commit hashes and statements in it are true as of the
date they were written and are not kept current.

For using DwarfMapper, start at the [README](../README.md) and [`docs/`](../docs). Some scripts and gates read files
here (for example `ledgers/equivalent-mutants.md`), so the folder stays at this path.
