# Design specs and implementation plans

Maintainers' working documents: `specs/` holds the design written before a feature was built, `plans/` the
step-by-step plan it was built from. Both are dated and not kept current; code blocks in them are sketches of code
that did not exist yet when they were written, which is why the documentation pipeline does not check them.

For the library as it is today, read the [README](../../README.md) and the rest of [`docs/`](..).
